# AstroType: Pertahanan Galaksi & Akademi Mengetik 10 Jari 🚀
> **Created & Developed by YRZQ_WLDN**  
> *Versi 2.5 • Space Touch-Typing Combat Simulator & Progressive Web App*

---

AstroType adalah game pertahanan luar angkasa sekaligus platform edukasi mengetik 10 jari (*Touch Typing Odyssey*) modern berkecepatan tinggi yang dibangun murni menggunakan teknologi web modern (HTML5 Canvas, Vanilla CSS, dan Web Audio API) tanpa dependensi berat.

## ✨ Fitur-Fitur Unggulan

### 1. 🎓 Simulator Akademi 10 Jari
- 12 modul pelatihan terstruktur dari dasar *Home Row* (`ASDF JKL;`), *Upper Row* (`QWERTY`), *Lower Row* (`ZXCVB`), Baris Angka (`1-0`), hingga Kecepatan Penuh.
- **Pemandu Jari Interaktif**: Indikator jari real-time di HUD dan papan tuts warna-warni (*color-coded ergonomic zones*) untuk membimbing penempatan jari yang presisi.

### 2. 🛸 Hangar Armada & Kustomisasi Laser
Buka armada kapal tempur masa depan seiring naiknya level kadetmu:
- **Vanguard Falcon (Level 1)**: Kapal penjelajah standar dengan meriam ion cyan.
- **Solar Phoenix (Level 5)**: Ditempa di korona bintang dengan plasma surya berapi jingga.
- **Void Phantom (Level 10)**: Kapal siluman kuantum hampa udara dengan laser violet mistis.
- **Titan Dreadnought (Level 15)**: Benteng tempur bergerak kelas berat dengan meriam partikel radiasi emerald.

### 3. 🎵 Musik Latar Sintetis Prosedural (Synthwave BGM)
- Musik latar bergaya cyberpunk synthwave yang dihasilkan secara prosedural langsung melalui Web Audio API oscillators & low-pass filter (*Zero External Downloads* / 0 KB transfer file audio).
- Dapat dinyalakan/dimatikan secara instan lewat tombol di header atau modal pengaturan.

### 4. 🎯 Laboratorium Huruf Terlemah (*Weak Keys Targeted Drill*)
- Algoritma diagnostik pintar yang otomatis mencatat tombol yang paling sering salah ketik (*weak keys*).
- Tombol satu-klik untuk langsung membuat sesi latihan intensif khusus melatih kombinasi huruf-huruf yang lemah tersebut demi mempercepat memori otot (*muscle memory*).

### 5. 🎙️ Penyiar Suara Taktis Kokpit (*Cockpit Voice Announcer*)
- Radio komando taktis otomatis memanfaatkan *Web Speech Synthesis API*.
- Memberikan pengumuman suara saat mencapai *combo milestone* (10, 25, 50 combo), perisai kritis (< 30%), reaktor EMP penuh, dan saat mengalahkan bos induk armada musuh.

### 6. 📅 Misi Latihan Harian & Daily Streak
- Sistem pencatat kebiasaan latihan harian (*Daily Streak*) dengan penanda hari aktif.
- 3 target misi harian (Jumlah musuh hancur, target WPM, dan penggunaan EMP) dengan bonus +300 XP setiap hari.

### 7. 👻 Ghost Typist / Rekor Bayangan
- Indikator kecepatan pacu real-time pada speedometer HUD yang menampilkan selisih kecepatan ketikmu secara dinamis melawan rekor terbaik (*Personal Best*): `+X WPM vs Rekor`.

### 8. 📜 Sertifikat Kelulusan Resmi Digital
- Generator diploma resmi beresolusi tinggi dengan nomor validasi unik, segel emas akademi antariksa, dan tanda tangan resmi **Laksamana Utama: YRZQ_WLDN**.
- Dapat diunduh langsung sebagai file gambar PNG jernih untuk dibagikan.

### 9. 📤 1-Click WhatsApp & Web Social Share
- Bagikan pencapaian WPM, Akurasi, dan Rank kelulusanmu langsung ke WhatsApp atau media sosial dengan satu sentuhan.

### 10. 📱 Mobile & PWA Ready
- 100% responsif untuk semua ukuran layar (Desktop, Tablet, dan Smartphone Android / iOS).
- Dilengkapi keyboard virtual on-screen interaktif dan integrasi keyboard bawaan HP (*Gboard / iOS Keyboard*) tanpa jeda (*zero latency*).
- Getaran taktil *Haptic Feedback* pada perangkat mobile.
- Siap di-*Add to Home Screen* sebagai Progressive Web App (PWA) lengkap dengan Service Worker & App Manifest.

## 🚀 Cara Hosting di Vercel

Game ini 100% murni web statis dan telah dilengkapi konfigurasi `vercel.json`:

1. Upload seluruh folder ini ke repository GitHub Anda.
2. Buka dashboard [Vercel](https://vercel.com/) lalu klik tombol **Add New Project**.
3. Pilih repository GitHub game ini.
4. Pada bagian **Framework Preset**, pilih **Other** (karena murni web statis).
5. Klik tombol **Deploy**.
6. Website AstroType akan langsung online dengan domain HTTPS gratis dari Vercel dalam hitungan detik!
